# Mesh Modularizer (メッシュモジュラライザー)

Unity / VRChat 向けの汎用メッシュ切り分け・Prefab分離ツールです。
メッシュの一部（衣装、アクセサリー、体の一部など）を直感的に選択し、元の位置や階層構造、
そして **元のコンポーネントをそのまま保ったまま** 独立した新規 Prefab / Mesh アセットとして安全に切り出すことができます。

---

## 動作方式: 減算方式

このツールは **切り出し元メッシュを持つ Prefab を丸ごと複製し、不要なものを削り落とす** という方式で動作します。

1. 選択したポリゴンから新しい Mesh アセットを生成する
2. **切り出し元メッシュを持つ Prefab**（アバター全体ではなく、最も内側の Prefab インスタンス）を複製する
3. 複製した Renderer に、切り出したメッシュを差し込む
4. 不要になったオブジェクト / コンポーネントを削除する
5. Prefab として保存する

新しい階層を組み立て直すのではなく複製から削っていくため、Transform 値・Renderer 設定・
各種コンポーネントの値と参照が、追加の転写処理なしにそのまま維持されます。

> ボーンが Prefab の外にある場合のみ、それらを含む最小の共通祖先まで複製範囲が自動的に広がります
> （その旨がウィンドウ下部に表示されます）。

## 主な特徴

1. **階層・位置の完全維持**:
   - 元のオブジェクトと同じローカル Transform、階層構造、rootBone、bones、localBounds を維持します。
   - 生成された Prefab を元の親の下に置くだけで、元の位置にズレなくピッタリ重なります。

2. **コンポーネント維持方針を選択可能**:
   - **全て維持**: 切り出し対象以外の Renderer と不要な PhysBone 以外は、全てのコンポーネントを残します。
     VRC Contact、Constraint、Modular Avatar のコンポーネント、独自スクリプトなども残ります。
   - **メッシュ依存のみ** (Module Creator 相当): Renderer / MeshFilter / PhysBone /
     PhysBoneCollider / Constraint だけを残し、それ以外は全て除去します。

3. **不要な PhysBone の自動除去**:
   - どちらの方針でも、切り出したメッシュのウェイトに一切影響しなくなった PhysBone は除去されます。
   - 判定には「実際にウェイトが載っているボーン」を使うため、ボーン階層をそのまま残す設定でも正しく機能します。
   - 生き残った PhysBone が参照する PhysBoneCollider は、参照をたどって自動的に維持されます。

4. **参照の追跡**:
   - 残すコンポーネントが参照している Transform / コンポーネントを推移的にたどり、参照先が
     消えてしまわないようにします（Constraint の source なども含む）。
   - 複製範囲の外を指す参照があった場合は件数を警告として表示します。

5. **SkinnedMeshRenderer & MeshRenderer 両対応**:
   - スキンメッシュ（服・髪・体）だけでなく、通常の静的メッシュ（アクセサリー・小道具）も切り出し可能です。

6. **直感的な選択機能**:
   - **UVアイランド選択**: UV展開図上でひとまとまりのアイランド単位で選択。
   - **連結ポリゴン選択**: メッシュ空間上で頂点を共有して繋がっているポリゴン単位で選択。
   - **UVプレビュー**: ズーム・パン・矩形ドラッグ選択に対応。
   - **SceneView オーバーレイ**: シーンビュー上で直接メッシュをクリック / ドラッグして直感的に選択可能。

7. **オプショナルな最適化機能**:
   - **ウェイトの無いボーンを除去**: bones 配列と階層の両方から未使用ボーンを取り除きます。
   - **Bounds の再計算**: スキニング姿勢と BlendShape を考慮したタイトな localBounds を自動計算。
   - **MA Bone Proxy の付与**: Modular Avatar 環境で自動的に Bone Proxy を設定。
   - **全サブメッシュ一括分離**: 1クリックで全サブメッシュを個別 Prefab として一括書き出し。

## 使い方

1. メニューバーの `Window > dennokoworks > Mesh Modularizer` (または `Tools > dennokoworks > Mesh Modularizer`) を開きます。
2. **切り出し元メッシュ** に対象の Renderer (SkinnedMeshRenderer または MeshRenderer) を指定します
   （ヒエラルキーで選択して「選択から取得」を押すこともできます）。
   - シーン上に配置されたオブジェクトを指定してください。Prefab アセットを直接指定することはできません。
3. UV プレビューまたはシーンビュー上で、切り出したいパーツのポリゴンを選択します。
4. **コンポーネントの維持** で方針を選びます。
5. **パーツ出力設定** でパーツ名や保存先フォルダを確認します。
6. **「選択範囲をパーツPrefabとして書き出し」** を押すと、新規 Mesh アセットと Prefab が生成され、
   元の Prefab と同じ親の下にシーン配置されます。

## 設定項目

| 項目 | 説明 |
|---|---|
| 全て維持 / メッシュ依存のみ | コンポーネントの維持方針 |
| PhysBone を維持 | OFF にすると PhysBone を全て除去します（ON でも不要なものは除去されます） |
| Constraint を維持 | Unity Constraint / VRChat Constraint を残すかどうか |
| 対象以外の Renderer を除去 | 「全て維持」時のみ有効。「メッシュ依存のみ」では常に除去されます |
| BlendShape を維持 | 切り出したメッシュに BlendShape を引き継ぎます |
| ウェイトの無いボーンを除去 | bones 配列と階層から未使用ボーンを取り除きます |
| Bounds を再計算 | OFF なら元の localBounds をそのまま維持します |
| 書き出し後にシーンへ配置 | 生成した Prefab を自動でシーンに配置します |
| MA Bone Proxy を付与 | Modular Avatar がインストールされている場合のみ有効 |

---

## 注意点

- 出力される Prefab は、元の Prefab との接続を解除した独立した Prefab です（Prefab Variant にはなりません）。
- 「全て維持」でも、切り出し対象以外の Renderer / MeshFilter は既定で除去されます（パーツとして切り出すため）。
- 複製範囲の外を指していた参照（例: 他のアバターの骨を指す Probe Anchor や Constraint の source）は、
  Prefab 化の時点で外れます。件数はウィンドウ下部に表示されます。
- 元のオブジェクト・メッシュアセットには一切変更を加えません。
