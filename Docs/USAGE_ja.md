# Mesh Splitter (メッシュスプリッター)

Unity / VRChat 向けのメッシュ切り分け・Prefab分離ツールです。
メッシュの一部（衣装、アクセサリー、髪、体の一部など）を直感的に選択し、元の位置や階層構造、必要なコンポーネント（PhysBone、Constraint等）を維持したまま、独立した Prefab / Mesh として安全に切り出すことができます。

元のメッシュやアバターには一切変更を加えません。

---

## クイックスタート（3ステップで切り出し）

### Step 1: ツールを開いて対象メッシュを指定する
1. メニューバーの `dennokoworks > Mesh Splitter` を開きます。
2. ヒエラルキーで切り分けたいオブジェクトを選択し、**「選択から取得」** をクリックします（直接「対象メッシュ」欄へドラッグ＆ドロップでも指定可能）。

### Step 2: 切り出したい部分を選択する
1. 選択単位を選びます：
   - **UVアイランド**: UV展開図の島単位で選択
   - **つながったポリゴン**: 3D空間上でつながっているポリゴン単位で選択
2. ウィンドウ内の **UVプレビュー**（左ドラッグで矩形選択、右ドラッグで移動、ホイールで拡大縮小）または **シーンビュー上** で直接クリック/ドラッグして切り出したい部分を選択します。

### Step 3: Prefabとして書き出す
1. **「Prefab名」** に出力したい名前を入力します。
2. **「選択範囲をパーツPrefabとして書き出し」** をクリックします。
3. 指定したフォルダに新規 Mesh アセットと独立した Prefab が出力され、シーン上の元の位置に自動配置されます。

## 画面構成と各項目の説明

### 1. トップバー
- **バージョン表示**: 現在のバージョンを表示します。更新がある場合は自動で通知されます。
- **↻ (再確認ボタン)**: 最新バージョンの有無を手動で再チェックします。
- **言語切り替え (`EN` / `JA`)**: UI の表示言語を英語 / 日本語で切り替えます（設定は保存されます）。

### 2. 対象メッシュ
切り出し元となるメッシュを指定するセクションです。
- **対象メッシュ**: 切り出したい SkinnedMeshRenderer または MeshRenderer を指定します。
- **選択から取得**: シーンやヒエラルキーで現在選択中のオブジェクトを自動でセットします。
- **↻ (再読み込み)**: メッシュの構造やサブメッシュ情報を再解析します。
- **サブメッシュを指定**: 特定のマテリアル/サブメッシュに限定して選択したい場合に指定します。
- **UVチャンネル (`UV0` / `UV1` ...)**: UVアイランドの判定に使う UV チャンネルを選びます。メッシュが実際に持っているチャンネルだけが並びます（通常は `UV0` のままで問題ありません）。

### 3. 範囲選択
切り出すポリゴンの範囲を選択するセクションです。
- **UVアイランド**: UV展開図のアイランド単位で選択します。
- **つながったポリゴン**: 3Dメッシュ上で頂点を共有して連続しているパーツ単位で選択します。
- **全選択 / クリア / 反転**: 現在の選択状態を一括操作します。
- **UVプレビュー**: UV展開図上で選択範囲を確認・ドラッグ選択できます。灰色の枠が UV の 0〜1 の範囲です。
- **メインテクスチャの表示**: **サブメッシュを指定** していて、かつ **UVチャンネルが `UV0`** のときは、そのサブメッシュに割り当てられたマテリアルのメインテクスチャを UVプレビューの背景に表示します。どこを選んでいるのかがテクスチャ上で確認できます。
  - lilToon / Poiyomi / Unity 標準シェーダーなど、メインテクスチャ（`_MainTex`）を UV0 から参照するマテリアルが対象です。タイリングとオフセットの設定は反映されますが、繰り返しの表示はせず、テクスチャ1枚分だけを敷きます。
  - 次の場合は背景を表示しません: サブメッシュが **すべて** のとき / `UV1` 以降を選んでいるとき / Poiyomi でメインテクスチャの UV 設定が `UV0` 以外のとき。
  - UV スクロールや回転などのアニメーション設定は反映されません。
- **シーンでクリック選択 (ON/OFF)**: 3Dシーンビュー上で直接メッシュをクリック・ドラッグして選択できます。
- **ワイヤーフレーム透過**: シーンビュー上でメッシュの裏側にあるワイヤーフレームも透過して見やすく表示します。

### 4. Prefab化
選択したメッシュを新規アセットおよび Prefab として出力するセクションです。
- **Prefab名**: 生成される Prefab および Mesh アセットの名前です。
- **保存先フォルダ**: アセットが出力されるプロジェクト内のフォルダ（デフォルト: `Assets/MS_splitted_mesh`）。
- **選択範囲をパーツPrefabとして書き出し**: 選択したポリゴンを新しい独立した Prefab として書き出します。
- **全サブメッシュを個別のPrefabに一括書き出し**: メッシュに含まれるすべてのサブメッシュを、それぞれ個別の Prefab として一括で書き出します。

## 主な特徴・安心設計

- **位置・階層のズレなし**: 元の Transform やボーン構造、バウンズが正確に維持されるため、生成された Prefab を元の親の下に置くだけでピッタリ重なります。
- **必要なコンポーネントだけを自動抽出**: 切り出すメッシュに関連するボーンや PhysBone、PhysBoneCollider、Constraint だけを自動で判別して引き継ぎます。アバター本体の設定（VRC Avatar Descriptor や Animator など）が混ざることはありません。
- **非破壊**: 元のアバターやメッシュアセットは一切変更されません。
- **スキンメッシュ・静的メッシュ両対応**: 衣装・髪・体などの SkinnedMeshRenderer はもちろん、アクセサリー・小物などの通常の MeshRenderer にも対応しています。
