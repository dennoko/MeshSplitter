# Mesh Modularizer (メッシュモジュラライザー)

Unity / VRChat 向けの汎用メッシュ切り分け・Prefab分離ツールです。
メッシュの一部（衣装、アクセサリー、体の一部など）を直感的に選択し、元の位置や階層構造、
そして **元のコンポーネントをそのまま保ったまま** 独立した新規 Prefab / Mesh アセットとして安全に切り出すことができます。

---

## 動作方式: 減算方式

このツールは **切り出し元メッシュを持つ Prefab を丸ごと複製し、不要なものを削り落とす** という方式で動作します。

1. 選択したポリゴンから新しい Mesh アセットを生成する
2. **切り出し元メッシュを持つ Prefab**（アバター全体ではなく、最も内側の Prefab インスタンス）を複製する
3. 複製した Renderer に、切り出したメッシュを差し込む
4. 不要になったオブジェクト / コンポーネントを削除する
5. Prefab として保存する

新しい階層を組み立て直すのではなく複製から削っていくため、Transform 値・Renderer 設定・
各種コンポーネントの値と参照が、追加の転写処理なしにそのまま維持されます。

> ボーンが Prefab の外にある場合のみ、それらを含む最小の共通祖先まで複製範囲が自動的に広がります
> （その旨がウィンドウ下部に表示されます）。

---

## 主な特徴

1. **階層・位置の完全維持**:
   - 元のオブジェクトと同じローカル Transform、階層構造、rootBone、bones、localBounds を維持します。
   - 生成された Prefab を元の親の下に置くだけで、元の位置にズレなくピッタリ重なります。

2. **スマートなコンポーネント自動維持**:
   - 切り出し対象以外の Renderer は自動除去されます。
   - 切り出したメッシュのウェイトに一切影響しなくなった PhysBone は自動で安全に除去され、必要な PhysBone や Constraint、PhysBoneCollider は自動で追跡・維持されます。

3. **安全なボーン自動剪定**:
   - 切り出しパーツでウェイトの載っているボーンおよびその親（祖先）ボーンを維持し、関係のない不要なボーンだけを階層から自動除去します。

4. **BlendShape & Bounds の自動最適化**:
   - BlendShape は常に安全に引き継がれます。
   - 切り出しメッシュの姿勢に応じた最適な localBounds が自動計算されます。

5. **SkinnedMeshRenderer & MeshRenderer 両対応**:
   - スキンメッシュ（服・髪・体）だけでなく、通常の静的メッシュ（アクセサリー・小道具）も切り出し可能です。

6. **直感的な選択機能**:
   - **UVアイランド選択**: UV展開図上でひとまとまりのアイランド単位で選択。
   - **連結ポリゴン選択**: メッシュ空間上で頂点を共有して繋がっているポリゴン単位で選択。
   - **UVプレビュー**: ズーム・パン・矩形ドラッグ選択に対応。
   - **SceneView オーバーレイ**: シーンビュー上で直接メッシュをクリック / ドラッグして直感的に選択可能。
   - **全サブメッシュ一括分離**: 1クリックで全サブメッシュを個別 Prefab として一括書き出し。

## 使い方

1. メニューバーの `Window > dennokoworks > Mesh Modularizer` (または `Tools > dennokoworks > Mesh Modularizer`) を開きます。
2. **切り出し元メッシュ** に対象の Renderer (SkinnedMeshRenderer または MeshRenderer) を指定します
   （ヒエラルキーで選択して「選択から取得」を押すこともできます）。
   - 指定すると自動的にメッシュが解析されます。
3. UV プレビューまたはシーンビュー上で、切り出したいパーツのポリゴンを選択します。
4. **パーツ出力** でパーツ名を確認します。
5. **「選択範囲をパーツPrefabとして書き出し」** を押すと、新規 Mesh アセットと Prefab が生成され、
   元の Prefab と同じ親の下に自動でシーン配置されます。

---

## 設定項目

| 項目 | 説明 |
|---|---|
| 切り出し元メッシュ | 対象の SkinnedMeshRenderer / MeshRenderer を指定 |
| 対象サブメッシュ | 特定のサブメッシュ（マテリアル単位）に絞り込んで選択する場合に指定 |
| 範囲選択 (UVアイランド / 連結ポリゴン) | 選択単位の切り替え |
| 全選択 / クリア / 反転 | 選択状態の一括操作 |
| パーツ名 | 生成する Prefab / Mesh アセットの名称 |
| 保存先フォルダ | アセットの出力先フォルダ (デフォルト: `Assets/MeshModularizer_Output`) |

---

## 注意点

- 出力される Prefab は、元の Prefab との接続を解除した独立した Prefab です（Prefab Variant にはなりません）。
- 複製範囲の外を指していた参照（例: 他のアバターの骨を指す Probe Anchor や Constraint の source）は、
  Prefab 化の時点で外れます。件数はウィンドウ下部に表示されます。
- 元のオブジェクト・メッシュアセットには一切変更を加えません。
